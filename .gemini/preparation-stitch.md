# Snapptale Project Details for "Google Stitch" Layout Update

This document summarizes the key details of the Snapptale project to inform the creation of a prompt for updating the layout with the "Google Stitch" design system.

## 1. Project Goal

Snapptale is an AI-powered storybook generator that creates personalized stories for children. The core goal is to transform a user-provided photo and name into a unique, downloadable storybook, fostering imagination and storytelling.

## 2. User Flow

The application follows a simple, linear flow:

1.  **Input:** The user uploads a photo and provides a name.
2.  **Processing:** The AI generates a 3-chapter story with one illustration per chapter.
3.  **Output:** The user receives a downloadable PDF of the final storybook.

## 3. Target Audience

The primary users are parents or guardians who want to create personalized and engaging stories for their children. The end-users are the children themselves, so the design should be appealing and accessible to them.

## 4. Brand Identity

The Snapptale brand is built around the concepts of **storytelling and adventure**. It aims to turn everyday moments ("Snaps") into imaginative narratives ("Tales").

### Brand Messaging

-   **Primary Slogan:** "Your Story, Your Adventure"
-   **Secondary Slogan:** "Turn a Snap into a Tale"

## 5. Visual Design System

### Color Palette

-   **Primary Color:** `#A8DADC` (Light Cyan)
-   **Secondary Color:** `#FFD6BA` (Light Peach)
-   **Highlight Color:** `#457B9D` (Steel Blue)
-   **Shadow / Text Color:** `#1D3557` (Dark Blue)
-   **Background Color:** `#F9FAFB` (Off-White)

### Typography

-   **Primary Font:** Poppins Bold (for headings and prominent text)
-   **Secondary Font:** Nunito Regular (for body text and general content)

## 6. Interaction and User Experience

### Loading Animations

Given that the AI generation process can take time, it's crucial to provide feedback to the user.

-   **Standard Loading:** For short processes (e.g., file uploads), a simple, clean loading indicator should be used. This could be a spinner or a pulsating version of the Snapptale logo.

-   **Extended Processing Animation:** For the main story generation, which can be a longer process, a more engaging and child-focused animation is needed. This animation should visually represent progress and keep the child's attention. Ideas include:
    -   An animated character on a path, moving forward as the story generation progresses.
    -   A "magic" progress bar that fills up with sparkles or changing colors.
    -   A sequence of simple, animated icons that represent story elements (e.g., a book opening, a pencil writing, a star appearing) for each chapter being generated.
